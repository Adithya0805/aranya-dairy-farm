# Aranya Organic Dairy Farm — Frontend Web Application

This directory contains the Next.js 16 (App Router + Turbopack) production frontend for **Aranya Organic Dairy Farm**.

For full architecture, Supabase schema, AI Assistant details, and complete documentation, please see the **[Root Repository README](../README.md)**.

## Quick Commands

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Run ESLint (0 errors, 0 warnings)
npm run lint

# Compile optimized Turbopack production build
npm run build
```
